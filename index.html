Onde os dados ficam?

Nesta primeira versão, os dados ficam no armazenamento local deste navegador (localStorage). Isso permite usar o site sem servidor, mas os dados não sincronizam entre dispositivos ou navegadores. Use o backup regularmente.

Para publicar uma biblioteca comunitária acessível por várias pessoas, a próxima etapa será conectar um banco de dados online (por exemplo, Supabase), autenticação e regras de moderação. Não há dados enviados para um servidor nesta versão.
